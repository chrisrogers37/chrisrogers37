i spent years doing data work — citadel, meta, msk — then quit and went all-in on ai. i built an autonomous agent fleet that writes most of my code now, and open-sourced the whole thing. these days i lead the data platform at artemis while the fleet keeps shipping. off the clock: maine, electronic music as crog, and too many side projects.

## tier 1 — what i'm building

### [Claudfather](https://github.com/Claudfather) &nbsp;—&nbsp; the recursion, made real

an autonomous fleet of claude code agents — a manager, engineers, a designer, reviewers — running on cheap hardware. they pick up tasks, open branches, write the code, review each other's pull requests, and ship end-to-end while i'm doing something else.

this readme? one of them drafted it.

the ecosystem, all open source under [**github.com/Claudfather**](https://github.com/Claudfather):

- **[Claudlobby](https://github.com/Claudfather/Claudlobby)** — fleet compositor. turns one config into a running team of agents on cheap hardware.
- **[clauDNA](https://github.com/Claudfather/clauDNA)** — the shared skills, agents, and hooks the fleet runs on.
- **[Claudosseum](https://github.com/Claudfather/Claudosseum)** — where the agents get measured.
