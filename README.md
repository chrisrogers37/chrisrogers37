i spent years doing data — citadel, meta, msk — then quit and went all-in on ai. i built an autonomous agent fleet that writes most of my code now, and open-sourced the whole thing. these days i lead the data platform at artemis while the fleet keeps shipping. off the clock: maine, electronic music as crog, too many side projects.

## what i'm building

**[Claudfather](https://github.com/Claudfather)** — an autonomous fleet of claude code agents (a manager, engineers, a designer, reviewers) that picks up tasks, opens branches, writes the code, reviews its own pull requests, and ships end-to-end while i'm doing something else. this readme was drafted by one of them.

[claudlobby](https://github.com/Claudfather/Claudlobby) — fleet compositor &nbsp;·&nbsp; [clauDNA](https://github.com/Claudfather/clauDNA) — shared skills the agents run on &nbsp;·&nbsp; [Claudosseum](https://github.com/Claudfather/Claudosseum) — where they get measured
